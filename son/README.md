# Dossier des sons

Dépose ici n'importe quel fichier audio (`.mp3`, `.wav`, `.ogg`, `.m4a`, `.webm` ou `.aac`).

Dès que le fichier est poussé sur GitHub (et que GitHub Pages a republié le site, ce qui prend
en général moins d'une minute), il apparaît automatiquement dans le jeu — aucune modification
de code n'est nécessaire.

## Comment nommer un fichier

Le nom du fichier devient l'indice affiché aux joueurs à la fin de la manche. Utilise des tirets
ou underscores à la place des espaces :

- `chien-qui-aboie.mp3` → affiché « Chien qui aboie »
- `sonnette_de_velo.wav` → affiché « Sonnette de velo »
- `eternuement.ogg` → affiché « Eternuement »

## Conseils

- Privilégie des sons courts (2 à 8 secondes) et reconnaissables : un cri d'animal, un bruit
  d'objet, un effet sonore plutôt qu'une musique complète.
- Évite les fichiers trop volumineux (quelques centaines de Ko à 1-2 Mo suffisent) pour que le
  jeu charge vite.
- Respecte les droits d'auteur : utilise des sons libres de droits ou enregistrés par toi-même.
